浏览器配置（Profile 数据隔离）
每个配置对应一份独立的浏览器数据（Cookie / 书签 / 登录状态 / 缓存 / 扩展互不干扰）。在「已安装」页启动某个版本时，可用下拉框选择用哪个配置打开，从而实现多账号、多环境的隔离测试。「default」为内置默认配置，首次启动时自动创建。
